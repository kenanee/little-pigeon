# Ressources et crédits

Deep Escape utilise Three.js chargé depuis jsDelivr.

Les éléments 3D du jeu sont générés de manière procédurale dans le navigateur :
- requin jouable et ses variantes de couleurs ;
- orques poursuivantes ;
- fond marin, rochers, varech et coraux ;
- poissons, bulles et perles.

Aucun modèle externe de ville, voiture, pigeon ou nourriture n'est nécessaire. La musique et les effets sont synthétisés localement avec Web Audio.
